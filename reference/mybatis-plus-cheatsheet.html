MyBatis Plus 速查表

参考文档 | 打印友好 | 随查随用

MyBatis Plus 是 MyBatis 的增强工具包，继承 BaseMapper 即可获得 CRUD 能力，也可手写复杂 SQL。国内企业最流行的数据层方案。

常用注解

注解 用途 示例
@TableName("users") 类映射到数据库表 类名与表名不同时必须用
@TableId(type = IdType.AUTO) 主键，自增策略 PostgreSQL 用 IdType.AUTO
@TableField("user_name") 字段映射到列名 字段名与列名不同时用
@TableField(exist = false) 该字段不映射到数据库列 仅用于业务逻辑的临时字段

BaseMapper CRUD 方法

方法 SQL 等价 说明
insert(entity) INSERT INTO ... 插入，自增 id 自动回填
deleteById(id) DELETE WHERE id = ? 按主键删除
deleteByIds(idList) DELETE WHERE id IN (...) 批量删除
updateById(entity) UPDATE SET ... WHERE id = ? 按主键更新（null 字段不更新）
selectById(id) SELECT WHERE id = ? 按主键查单条
selectBatchIds(idList) SELECT WHERE id IN (...) 批量查询
selectList(wrapper) SELECT WHERE ... 条件查询，null = 查全部
selectOne(wrapper) SELECT WHERE ... LIMIT 1 查单条，多条会报错
selectCount(wrapper) SELECT COUNT(*) 计数

条件构造器 QueryWrapper

用于 selectList、selectOne、selectCount 等方法，拼接 WHERE 条件。

// 方式一：QueryWrapper（字符串字段名）
QueryWrapper<User> wrapper = new QueryWrapper<>();
wrapper.eq("name", "Vue");
List<User> users = userMapper.selectList(wrapper);
// SQL: SELECT * FROM users WHERE name = 'Vue'

// 方式二：LambdaQueryWrapper（方法引用，推荐）
LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
wrapper.eq(User::getName, "Vue");
List<User> users = userMapper.selectList(wrapper);

常用条件方法

方法 SQL 等价 示例
eq(field, value) field = value wrapper.eq(User::getName, "Vue")
ne(field, value) field != value wrapper.ne(User::getName, "Vue")
gt(field, value) field > value wrapper.gt(User::getId, 5)
ge(field, value) field >= value wrapper.ge(User::getId, 5)
lt(field, value) field < value wrapper.lt(User::getId, 10)
le(field, value) field <= value wrapper.le(User::getId, 10)
like(field, value) field LIKE %value% wrapper.like(User::getName, "Vu")
likeRight(field, value) field LIKE value% 前缀匹配
likeLeft(field, value) field LIKE %value 后缀匹配
in(field, list) field IN (...) wrapper.in(User::getId, Arrays.asList(1,2,3))
isNull(field) field IS NULL wrapper.isNull(User::getEmail)
orderByDesc(field) ORDER BY field DESC wrapper.orderByDesc(User::getId)
orderByAsc(field) ORDER BY field ASC wrapper.orderByAsc(User::getName)

链式调用示例

// 多条件 + 排序
LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<>();
wrapper.like(User::getName, "e")
       .gt(User::getId, 1)
       .orderByDesc(User::getId);
List<User> users = userMapper.selectList(wrapper);
// SQL: SELECT * FROM users
//      WHERE name LIKE '%e%' AND id > 1
//      ORDER BY id DESC

application.yml 常用配置

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl  # 打印 SQL
    map-underscore-to-camel-case: true                      # 下划线转驼峰
  global-config:
    db-config:
      id-type: auto          # 全局主键策略
      logic-delete-field: deleted  # 逻辑删除字段名
      logic-delete-value: 1        # 已删除值
      logic-not-delete-value: 0    # 未删除值

}

Lombok 简化

国内项目中常用 Lombok 注解替代手写 getter/setter：

@Data                  // getter/setter/toString/equals
@TableName("users")
public class User {
    @TableId(type = IdType.AUTO)
    private Long id;
    private String name;
    private String email;
}

加 @Data 后无需手写 getter/setter，IDEA 装 Lombok 插件即可。
