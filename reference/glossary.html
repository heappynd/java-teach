Java 后端术语表

参考文档 | 前端开发者专属版 | 持续更新

本文档将 Java 后端核心术语映射到你已熟悉的前端概念。每次新课遇到陌生术语，都可以回来查阅。

基础概念

术语 前端类比 说明
JDK
Java Development Kit		 Node.js 运行时 Java 开发工具包，包含编译器（javac）和运行时（JRE）。没有 JDK 就无法编译和运行 Java 代码，就像没有 Node.js 就不能运行 JS。
JRE
Java Runtime Environment		 浏览器 V8 引擎 Java 运行环境。JDK 包含 JRE。
JVM
Java Virtual Machine		 V8 引擎 Java 虚拟机，负责执行 Java 字节码。一次编写，到处运行靠的就是 JVM。
OpenJDK 开源版 Node.js Java SE 的开源实现。Adoptium Temurin、Amazon Corretto 等都是基于 OpenJDK 的发行版。

构建与依赖管理

术语 前端类比 说明
Maven npm / yarn Java 的项目管理和构建工具。管理依赖、编译、打包、测试，相当于 npm + Vite 的组合体。
Gradle pnpm / Vite 另一种构建工具，更灵活更快，但学习曲线更陡。Spring Initializr 默认提供 Maven 和 Gradle 两个选项。
pom.xml package.json Maven 的项目配置文件，声明项目信息和依赖。POM = Project Object Model。
GroupId / ArtifactId / Version @scope/package-name@version Maven 坐标（GAV），唯一标识一个依赖包。如 org.springframework.boot:spring-boot-starter-web:3.2.0。
Maven Repository npm registry (npmjs.com) 存放 Java 包的仓库。Maven Central 是公共仓库，相当于 npmjs.com。
~/.m2/repository node_modules Maven 的本地依赖缓存目录。所有下载的依赖都存在这里，被多个项目共享（不像 node_modules 每个项目单独存一份）。
Dependency npm package 项目依赖的第三方库。在 pom.xml 的 <dependencies> 中声明。
Starter 预设的依赖集合（如 Nuxt preset） Spring Boot 的依赖打包方案。如 spring-boot-starter-web 一次引入 Web 开发需要的所有依赖。

Spring Boot 核心概念

术语 前端类比 说明
Spring Boot Nuxt.js / Next.js Spring 框架的快速开发方案，自动配置、内嵌服务器，开箱即用。就像 Nuxt 对 Vue 的意义。
Spring Framework Vue.js 核心 Spring Boot 的底层框架。Spring Boot 简化了 Spring 的配置，就像 Nuxt 简化了 Vue 的工程化。
@SpringBootApplication createApp().mount() Spring Boot 应用入口注解，标记主启动类。等同于 Vue 应用的启动点。
Bean Vue 中的组件实例 由 Spring 容器管理的对象。Spring 帮你创建和管理这些对象，你需要时直接注入使用。
IoC / DI
控制反转 / 依赖注入		 Vue 的 provide/inject Spring 核心思想。对象由容器创建和注入，而不是手动 new。类似于 Vue 的依赖注入机制。
Auto-configuration Nuxt 的自动导入 Spring Boot 根据依赖自动配置 Bean。你引入了 web starter，它就自动配置好 Tomcat 服务器。

Web 层（API 开发）

术语 前端类比 说明
@RestController Express Router / Koa Controller 标记一个类为 REST API 控制器，自动将返回值转为 JSON。
@GetMapping / @PostMapping app.get() / app.post() 定义 HTTP 路由。@GetMapping("/users") 相当于 app.get('/users', handler)。
@RequestMapping Vue Router routes 定义 通用的路由映射注解，可指定 method。也是类级别的路由前缀。
@RequestParam req.query.name 获取 URL 查询参数。如 ?name=Amy 中的 name。
@PathVariable Vue Router 的 /users/:id 获取 URL 路径参数。如 /users/42 中的 42。
@RequestBody req.body 获取 POST/PUT 请求体的 JSON 数据。
DTO
Data Transfer Object		 TypeScript Interface 数据传输对象，用于定义 API 请求/响应的数据结构。类似 TS 的 interface。
Tomcat Vite dev server Web 服务器。Spring Boot 内嵌了 Tomcat，不需要单独安装，直接运行即可。

数据层（MyBatis Plus）

术语 前端类比 说明
MyBatis SQL 模板引擎 Java 的半自动 ORM 框架。手写 SQL，框架负责参数映射和结果映射。灵活度高，国内主流。
MyBatis-Plus MyBatis + 自动 CRUD MyBatis 的增强工具包。继承 BaseMapper 就能免手写 SQL 实现 CRUD，也可手写复杂 SQL。国内企业最流行的数据层方案。
Mapper 数据访问接口 定义数据库操作的接口。MyBatis Plus 的 Mapper 继承 BaseMapper 即可获得 CRUD 方法。
BaseMapper Prisma 的自动 CRUD MyBatis Plus 提供的通用 Mapper 接口。继承后自动获得 insert、deleteById、updateById、selectById、selectList 等方法。
Entity Prisma Model 映射到数据库表的 Java 类。一个 Entity 类 = 一张数据库表。用 @TableName 标注表名。
条件构造器
QueryWrapper / LambdaQueryWrapper		 Prisma 的 where 条件 MyBatis Plus 的链式查询构建器，用代码拼接 WHERE 条件，避免手写 SQL 字符串。

数据层（其他方案，了解即可）

术语 前端类比 说明
JPA
Java Persistence API		 ORM（如 Prisma） Java 的 ORM 标准。全自动 ORM，无需手写 SQL。Spring Data JPA 是其 Spring 封装。本课程不使用，但面试常考。
Hibernate Prisma 的底层引擎 JPA 的主流实现框架。

项目结构

术语 前端类比 说明
src/main/java src/ 存放 Java 源代码。
src/main/resources public/ 或 assets/ 存放配置文件和静态资源。
application.properties .env Spring Boot 配置文件。配置端口、数据库连接等。也可用 .yml 格式。
src/test/java tests/ 或 __tests__/ 存放测试代码。
target/ dist/ 编译输出目录。Maven 编译后的 .class 文件和打包的 .jar 都在这里。
Package
包		 文件夹 / 命名空间 Java 的代码组织单位，对应文件系统的目录。如 com.example.demo.controller 对应 com/example/demo/controller/ 目录。package 声明必须与目录路径一致。标准 Spring Boot 项目按层分包：controller、service、mapper、entity、config。详见 第 10 课。
Import import 语句 引入其他包中的类。同包内的类互相使用不需要 import，跨包必须 import。类比前端的 import UserCard from './components/UserCard.vue'。
@ComponentScan 递归目录扫描 Spring 自动扫描组件的机制。从启动类所在包开始，递归扫描所有子包。这就是启动类必须放根包的原因。

常用 Maven 命令

命令 前端类比 说明
mvn clean rm -rf dist/ 清理 target 目录。
mvn compile tsc / vite build 编译源代码。
mvn test npm test 运行测试。
mvn package npm run build 打包成 .jar 文件。
mvn spring-boot:run npm run dev 启动 Spring Boot 应用（开发模式）。
mvn install npm link 打包并安装到本地 Maven 仓库。
