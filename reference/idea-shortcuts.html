IntelliJ IDEA 快捷键速查表

参考文档 | Windows/Linux 版 | 持续更新

从 VS Code 转到 IDEA？这些快捷键是你最高频使用的。建议打印出来贴在屏幕旁边。

万能键

快捷键 作用 VS Code 对应
Alt + Enter 万能修复：自动导入、修复错误、生成代码 Ctrl + .（Quick Fix）

最高频操作

代码有红线？按 Alt + Enter。缺 import？按 Alt + Enter。不知道怎么写？按 Alt + Enter。这一个键解决了 80% 的问题。

代码补全

快捷键 作用 VS Code 对应
Ctrl + 空格 基础补全：输入 @Get 补全 @GetMapping 自动弹出
Ctrl + Shift + 空格 智能补全：根据上下文推荐，更精准 无直接对应
Tab 确认补全（替换光标后的内容） Tab
Enter 确认补全（不替换，插入） Enter

Live Templates（代码模板）

输入缩写 + Tab，自动展开成完整代码。这是 IDEA 最省时间的功能。

缩写 展开结果 前端类比
sout System.out.println(); 类似 clg -> console.log()
psvm public static void main(String[] args) {} -
fori for (int i = 0; i < ; i++) {} -
iter for (var item : list) {}（增强 for 循环） 类似 foreach
ifn if (var == null) {} -
inn if (var != null) {} -

代码生成

快捷键 作用 VS Code 对应
Alt + Insert 生成：构造器、getter/setter、toString、equals 等 需装插件
Ctrl + Alt + T 用 if/try/for 等包裹选中代码 -
Ctrl + D 复制当前行到下一行 Shift + Alt + ↓
Ctrl + Y 删除当前行 Ctrl + Shift + K

导航与查找

快捷键 作用 VS Code 对应
Ctrl + N 按类名搜索文件 Ctrl + P
Ctrl + Shift + F 全局搜索（跨文件） Ctrl + Shift + F
Ctrl + B 跳转到定义（按住 Ctrl 点也行） F12 / Ctrl+Click
Ctrl + Alt + B 跳转到接口的实现 -
Alt + ← / Alt + → 切换标签页 相同
Ctrl + E 最近打开的文件列表 Ctrl + Tab
Shift Shift Search Everywhere（搜一切） Ctrl + Shift + P

代码格式化

快捷键 作用 VS Code 对应
Ctrl + Alt + L 格式化代码（相当于 Prettier） Shift + Alt + F
Ctrl + Alt + O 清理无用 import 需装插件
Ctrl + Alt + I 自动缩进 -

运行与调试

快捷键 作用 VS Code 对应
Shift + F10 运行当前程序 F5
Shift + F9 调试运行（Debug 模式） F5（选 Debug）
F8 单步执行（不进入方法） F10
F7 单步执行（进入方法） F11
F9 继续运行到下一个断点 F5
Ctrl + F8 切换断点 F9

重构

快捷键 作用 VS Code 对应
Shift + F6 重命名（变量、方法、类） F2
F6 移动类到另一个包（自动更新 package 声明和所有 import） 拖拽文件到目标文件夹
Ctrl + Alt + V 提取变量：把表达式结果赋给新变量 -
Ctrl + Alt + M 提取方法：把选中代码封装成方法 -

最实用的 5 个快捷键（先记这些）

  1. Alt + Enter - 万能修复，有红线就按它
  2. sout + Tab - 快速打印
  3. Shift Shift - 搜一切
  4. Ctrl + B - 跳转到定义
  5. Shift + F10 - 运行程序
