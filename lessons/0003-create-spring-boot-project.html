第 3 课：创建第一个 Spring Boot 项目

预计用时：20 分钟 | 难度：入门 | 前置知识：第 2 课 Maven 安装

Spring Initializr 是什么？

JDK 和 Maven 都装好了，现在来创建你的第一个 Spring Boot 项目！

还记得前端怎么创建 Vue3 项目吗？

# 前端创建 Vue3 项目
npm create vue@latest

Java 也有类似的工具，叫 Spring Initializr（start.spring.io），它是 Spring 官方的项目生成器：

前端（你已熟悉）

npm create vue@latest

选配置 -> 自动生成项目 -> 解压即用

后端（今天学的）

start.spring.io

选配置 -> 自动生成项目 -> 解压即用

先装一个 IDE

写 Vue3 你可能用 VS Code，写 Java 也有几个选择：

IDE 前端类比 推荐度
IntelliJ IDEA Community（免费） WebStorm 社区版 最推荐 - Java 生态最好的 IDE，JetBrains 出品
VS Code + Extension Pack for Java 你正在用的 VS Code 推荐 - 熟悉度高，装插件即可

建议

如果你不想换 IDE，在 VS Code 中安装 Extension Pack for Java 和 Spring Boot Extension Pack 这两个插件包就够了。在 VS Code 扩展商店搜索即可。

如果想获得最佳 Java 开发体验，推荐下载 IntelliJ IDEA Community Edition（免费版，功能足够初学使用）。

创建项目

打开 Spring Initializr

打开浏览器，访问 https://start.spring.io

你会看到一个项目配置页面，类似 Vue CLI 的交互式配置。

配置项目参数

按以下设置配置：

选项 选择 说明
Project Maven 我们用 Maven，不用 Gradle
Language Java 不选 Kotlin 或 Groovy
Spring Boot 最新稳定版（不带 SNAPSHOT） 选版本号后面没有 "(SNAPSHOT)" 的
Group com.yourname 你的组织标识，类似 npm 的 @scope
Artifact demo 项目名，类似 npm 包名
Name demo 自动填充，不用改
Description My first Spring Boot project 项目描述，随意
Package name com.yourname.demo 自动填充，不用改
Packaging Jar 选 Jar 不选 War。Jar 可以直接 java -jar 运行
Java 21 我们装的 JDK 21

添加依赖

点击右上角 "Add Dependencies" 按钮，搜索并添加以下依赖：

依赖名 作用 前端类比
Spring Web Web 开发能力：REST API、内嵌 Tomcat 服务器 相当于 axios + express
Spring Boot DevTools 开发热重载，代码修改后自动重启 相当于 Vite 的 HMR

关于依赖

Spring Initializr 中的 "Dependencies" 就像 npm create vue 时选择是否要 Router、Pinia、Vitest 一样。你选的每个依赖都会自动写入 pom.xml（相当于 package.json）。

生成并下载项目

点击底部的 "GENERATE" 按钮，会下载一个 demo.zip 文件。

将 zip 解压到你的工作目录，比如 C:\coding\demo。

用 IDE 打开项目

VS Code：File -> Open Folder -> 选择 C:\coding\demo

IntelliJ IDEA：File -> Open -> 选择 C:\coding\demo 文件夹

首次打开会等一会

IDE 打开后会自动运行 Maven 下载依赖（就像 npm install）。首次需要下载 Spring Boot 框架，可能需要 1-3 分钟。看右下角状态栏有进度条。配置了阿里云镜像会快很多。

理解项目结构

项目打开后，让我们对比一下 Spring Boot 和 Vue3 的项目结构：

Vue3 项目

my-vue-app/
├── index.html
├── package.json      <-- 依赖声明
├── vite.config.ts    <-- 构建配置
├── src/
│   ├── main.ts       <-- 入口文件
│   ├── App.vue       <-- 根组件
│   └── components/
├── public/
└── node_modules/     <-- 依赖（每项目独立）

Spring Boot 项目

demo/
├── pom.xml           <-- 依赖声明
├── src/
│   ├── main/
│   │   ├── java/
│   │   │   └── com/yourname/demo/
│   │   │       └── DemoApplication.java  <-- 入口
│   │   └── resources/
│   │       └── application.properties    <-- 配置
│   └── test/
│       └── java/
│           └── com/yourname/demo/
│               └── DemoApplicationTests.java
├── mvnw / mvnw.cmd   <-- Maven Wrapper
└── target/           <-- 编译输出（= dist/）

关键文件解读

文件 前端类比 作用
pom.xml package.json 声明项目信息和依赖。Maven 读取它来构建项目
DemoApplication.java main.ts 程序入口。@SpringBootApplication 注解标记，相当于 createApp(App).mount('#app')
application.properties .env 配置文件：服务器端口、数据库连接等。也可以用 .yml 格式
mvnw.cmd npx Maven Wrapper，让没装 Maven 的人也能构建项目。类似 npx
target/ dist/ 编译输出目录，运行 mvn compile 后生成

看看入口文件

打开 src/main/java/com/yourname/demo/DemoApplication.java：

package com.yourname.demo;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }

}

别被这段代码吓到，逐行翻译：

Java 代码 前端类比 含义
package com.yourname.demo; 命名空间 / 文件路径 声明这个类属于哪个包。对应目录结构 com/yourname/demo/
import org.springframework...* import { createApp } from 'vue' 导入 Spring Boot 框架的类
@SpringBootApplication createApp(App) 告诉 Spring：这是应用入口，自动配置启动
public class DemoApplication export default { ... } 定义一个类。Java 一切皆类，不像 JS 可以有独立函数
public static void main(String[] args) 程序入口函数 Java 程序的起点，相当于浏览器加载 JS 时第一个执行的代码
SpringApplication.run(...) .mount('#app') 启动 Spring Boot 应用，启动内嵌的 Tomcat 服务器

运行项目

方式一：用 Maven 命令运行

在项目根目录（pom.xml 所在目录）打开终端：

PS C:\coding\demo> mvn spring-boot:run

首次运行会编译代码并启动内嵌 Tomcat 服务器。看到类似以下输出说明成功了：

. ____ _ __ _ _ /\\ / ___'_ __ _ _(_)_ __ __ _ \ \ \ \ ( ( )\___ | '_ | '_| | '_ \/ _` | \ \ \ \ \\/ ___)| |_)| | | | | || (_| | ) ) ) ) ' |____| .__|_| |_|_| |_\__, | / / / / =========|_|==============|___/=/_/_/_/ :: Spring Boot :: (v4.1.0) INFO --- Tomcat initialized with port 8080 (http) INFO --- Started DemoApplication in 2.134 seconds

打开浏览器访问 http://localhost:8080，你会看到一个错误页面（Whitelabel Error Page）。别慌，这是正常的！因为我们还没写任何接口。

前端类比

就像你 npm run dev 启动了 Vite 开发服务器，但还没写任何路由，访问页面是空白的一样。Spring Boot 已经跑起来了，只是还没有 API 接口。

按 Ctrl + C 停止运行。

方式二：用 IDE 运行（推荐）

VS Code：打开 DemoApplication.java，在 main 方法上方会出现 "Run" 按钮，点击即可。

IntelliJ IDEA：打开 DemoApplication.java，点击 main 方法旁边的绿色三角形运行按钮。

IDE 运行方式更方便，支持断点调试，后续开发推荐用这种方式。

小测验

Spring Initializr 中的 "Dependencies" 相当于前端什么操作？

  • 相当于配置 ESLint 规则
  • 相当于选择要装哪些库
  • 相当于配置 Webpack 打包
  • 相当于设置 TypeScript 版本

小测验

访问 localhost:8080 出现错误页面是为什么？

  • 因为 Spring Boot 启动失败了
  • 因为还没有定义任何接口
  • 因为端口 8080 被占用
  • 因为 JDK 版本不兼容
