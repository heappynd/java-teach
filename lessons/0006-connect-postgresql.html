第 6 课：连接 PostgreSQL + MyBatis Plus

预计用时：40 分钟 | 难度：进阶 | 前置知识：第 5 课 路径参数与 DTO

目标：让数据真正持久化

上一课的用户管理 API 能跑，但数据存在内存里 -- 重启就没了。这节课我们换上真正的数据库：PostgreSQL + MyBatis Plus，让数据持久化。

前端（你已熟悉）

Vue3 + Prisma 连接 PostgreSQL

定义 Model -> 自动 CRUD -> 数据持久化

后端（今天学的）

Spring Boot + MyBatis Plus 连接 PostgreSQL

定义 Entity + Mapper -> 自动 CRUD -> 数据持久化

第一步：安装 PostgreSQL

下载并安装

打开 PostgreSQL Windows 下载页，下载 EDB 安装包。运行安装程序，关键步骤：

  1. 选择安装目录（默认即可）
  2. 选择组件：保留 PostgreSQL Server 和 Command Line Tools，pgAdmin 4 可以取消勾选（我们用 DBeaver 替代）
  3. 设置 postgres 用户密码 -- 务必记住！（比如 123456）
  4. 端口保持默认 5432

关键

安装时设置的 postgres 密码后面配置数据库连接要用。务必记住！

安装 DBeaver（数据库管理工具）

实际工作中不用 pgAdmin，用 DBeaver -- 免费开源，支持所有主流数据库，国内开发团队常用。

打开 DBeaver 下载页，下载 Windows 版安装包（.exe），一路下一步安装即可。

安装后打开 DBeaver，点击左上角插头图标（或 Database -> New Connection），连接 PostgreSQL：

参数 值
Host localhost
Port 5432
Database postgres（默认数据库，先连上再说）
Username postgres
Password 你安装时设置的密码

点击"测试连接"（Test Connection），第一次会提示下载 PostgreSQL 驱动，点下载即可。测试成功后点"完成"。

第二步：创建数据库和表

创建数据库

在 DBeaver 左侧右键连接 -> Create New Database，名称填 mydb，点击确定。

或者直接用 SQL：在 DBeaver 中按 Ctrl + ] 打开 SQL Editor，执行：

CREATE DATABASE mydb;

创建 users 表

在 DBeaver 中切换到 mydb 数据库（左侧双击），按 Ctrl + ] 打开 SQL Editor，执行：

CREATE TABLE users (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(200)
);

INSERT INTO users (name, email) VALUES
    ('Vue', 'vue@dev.com'),
    ('React', 'react@dev.com'),
    ('Angular', 'angular@dev.com');
SQL 说明
BIGSERIAL PostgreSQL 自增整数主键（类似 MySQL 的 BIGINT AUTO_INCREMENT）
VARCHAR(100) 变长字符串，最大 100 字符
PRIMARY KEY 主键，唯一标识每行记录

第三步：添加 Maven 依赖

在 pom.xml 的 <dependencies> 中添加：

<!-- MyBatis Plus（Spring Boot 4.x 版本）-->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot4-starter</artifactId>
    <version>3.5.17</version>
</dependency>

<!-- PostgreSQL 驱动 -->
<dependency>
    <groupId>org.postgresql</groupId>
    <artifactId>postgresql</artifactId>
</dependency>

关于版本号

MyBatis Plus 的 starter 与 Spring Boot 大版本一一对应，选错会启动报错。到 官方安装文档 查看最新版本。PostgreSQL 驱动版本由 Spring Boot 自动管理，不需要写 <version>。

JDK 8 / Spring Boot 2.x

MyBatis Plus 为不同的 Spring Boot 大版本提供了不同的 starter，API 用法完全相同：

Spring Boot JDK 要求 artifactId
4.x JDK 17+ mybatis-plus-spring-boot4-starter
3.x JDK 17+ mybatis-plus-spring-boot3-starter
2.7.x JDK 8 mybatis-plus-boot-starter

三者版本号统一（如 3.5.17），只是 artifactId 不同。

第四步：配置数据库连接

将 src/main/resources/application.properties 重命名为 application.yml（删除原 properties 文件，否则会覆盖 yml），写入：

spring:
  datasource:
    url: jdbc:postgresql://localhost:5432/mydb
    username: postgres
    password: 123456  # 换成你安装时设置的密码
    driver-class-name: org.postgresql.Driver

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl
    map-underscore-to-camel-case: true
配置项 说明
url 数据库连接地址：jdbc:postgresql://主机:端口/库名
log-impl: StdOutImpl 控制台打印 SQL -- 学习阶段必备，能看到 MyBatis Plus 生成了什么 SQL
map-underscore-to-camel-case 下划线转驼峰：数据库 user_name -> Java userName

第五步：创建 User Entity

上一课用 record 定义 User。但 MyBatis Plus 需要无参构造器和 setter 来填充数据 -- record 两者都没有。所以数据库 Entity 必须用普通类。

JDK 8 兼容

本节 Entity 代码使用普通类 + getter/setter，完全兼容 JDK 8。MyBatis Plus 的要求恰好与 JDK 8 一致 -- 不存在兼容性问题。

将 User.java 替换为：

package com.yourname.demo;

import com.baomidou.mybatisplus.annotation.IdType;
import com.baomidou.mybatisplus.annotation.TableId;
import com.baomidou.mybatisplus.annotation.TableName;

@TableName("users")  // 映射到 users 表
public class User {

    @TableId(type = IdType.AUTO)  // 主键，自增
    private Long id;
    private String name;
    private String email;

    public User() {}  // 无参构造器（MyBatis Plus 必需）

    public User(Long id, String name, String email) {
        this.id = id;
        this.name = name;
        this.email = email;
    }

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }

    public String getName() { return name; }
    public void setName(String name) { this.name = name; }

    public String getEmail() { return email; }
    public void setEmail(String email) { this.email = email; }
}
注解 Prisma 类比 说明
@TableName("users") @@map("users") 类映射到 users 表
@TableId(type = IdType.AUTO) @id @default(autoincrement()) 主键自增，插入时不需手动设置 id
无参构造器 + setter - MyBatis Plus 查到数据后 new User() 再逐个 setter。没有这些会报错

为什么 record 不行？

record 的字段是 final 的（没有 setter），也没有无参构造器。所有 Java ORM 框架（MyBatis Plus、JPA/Hibernate）都依赖无参构造 + setter 填充数据。数据库 Entity 必须用普通类，这是 Java 后端通用约定。

第六步：创建 UserMapper

新建 UserMapper.java：

package com.yourname.demo;

import com.baomidou.mybatisplus.core.mapper.BaseMapper;

public interface UserMapper extends BaseMapper<User> {
    // 空的！继承 BaseMapper 就自动有了 CRUD
}

在主启动类上加 @MapperScan：

@SpringBootApplication
@MapperScan("com.yourname.demo")  // 告诉 MyBatis Plus 去哪找 Mapper
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);
    }
}

Prisma（前端类比）

const prisma = new PrismaClient()
// 自动就有 CRUD
prisma.user.findMany()
prisma.user.create({ data })
prisma.user.delete({ where })

MyBatis Plus

interface UserMapper
    extends BaseMapper<User> {}
// 自动获得 CRUD
userMapper.selectList(null)
userMapper.insert(user)
userMapper.deleteById(id)

BaseMapper 自动提供的方法（完整列表见 MyBatis Plus 速查表）：

方法 Prisma 类比 作用
insert(user) prisma.user.create() 插入一条记录
deleteById(id) prisma.user.delete() 按 ID 删除
updateById(user) prisma.user.update() 按 ID 更新
selectById(id) prisma.user.findUnique() 按 ID 查询单条
selectList(null) prisma.user.findMany() 查询全部（null = 无条件）

第七步：重构 UserController

把内存 List 版本换成数据库版本。替换 UserController.java：

package com.yourname.demo;

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController
@RequestMapping("/users")
public class UserController {

    @Autowired  // Spring 自动注入 UserMapper（依赖注入）
    private UserMapper userMapper;

    @GetMapping
    public List<User> getAll() {
        return userMapper.selectList(null);
    }

    @GetMapping("/{id}")
    public User getById(@PathVariable Long id) {
        return userMapper.selectById(id);
    }

    @PostMapping
    public User create(@RequestBody User user) {
        userMapper.insert(user);
        return user;  // insert 后 user.id 会被自动回填
    }

    @DeleteMapping("/{id}")
    public String delete(@PathVariable Long id) {
        userMapper.deleteById(id);
        return "Deleted user " + id;
    }
}
变化 之前（内存版） 现在（数据库版）
数据存储 List<User> users PostgreSQL users 表
获取全部 return users userMapper.selectList(null)
获取单个 users.stream().filter(...) userMapper.selectById(id)
创建 users.add(user) userMapper.insert(user)
删除 users.removeIf(...) userMapper.deleteById(id)

@Autowired 是什么？

@Autowired 让 Spring 自动创建并注入 UserMapper 实例。不需要 new UserMapper()，相当于 Vue 的 inject() -- 你声明"我需要 UserMapper"，框架自动给你。

第八步：运行并测试

启动项目

运行 DemoApplication。配置正确的话控制台不会报错。

常见错误

连接失败：检查 PostgreSQL 服务是否启动、密码是否正确。

Mapper 未找到：确保主启动类加了 @MapperScan("com.yourname.demo")。

测试 GET 获取所有用户

浏览器访问 http://localhost:8080/users：

[{"id":1,"name":"Vue","email":"vue@dev.com"},
 {"id":2,"name":"React","email":"react@dev.com"},
 {"id":3,"name":"Angular","email":"angular@dev.com"}]

数据来自数据库！控制台会打印 MyBatis Plus 生成的 SQL：

==> Preparing: SELECT id,name,email FROM users ==> Parameters: <== Total: 3

测试 POST 创建用户

POST http://localhost:8080/users
Content-Type: application/json

{"name":"Svelte","email":"svelte@dev.com"}

响应：

{"id":4,"name":"Svelte","email":"svelte@dev.com"}

请求体中不需要传 id（数据库自增）。insert 后 MyBatis Plus 会把自增 id 回填到 user 对象中。

重启验证持久化

重启 Spring Boot 应用，再次访问 GET /users。Svelte 还在！数据已持久化到 PostgreSQL，不再随重启丢失。

架构总览

浏览器 / Vue3 前端
       │ HTTP 请求
       ▼
┌─────────────────────┐
│  UserController     │  ← 处理 HTTP 请求
│  @RestController    │
└────────┬────────────┘
         │ 调用
         ▼
┌─────────────────────┐
│  UserMapper         │  ← 数据访问层
│  extends BaseMapper │     自动生成 SQL
└────────┬────────────┘
         │ SQL
         ▼
┌─────────────────────┐
│  PostgreSQL         │  ← 数据库
│  users 表           │
└─────────────────────┘

这就是后端最经典的三层架构：Controller -> Mapper -> Database。你在 Vue3 前端用 axios 调用的接口，背后就是这个结构。

小测验

继承 BaseMapper 后自动获得了什么？

  • 免手写 CSS 的页面样式
  • 免手写 SQL 的增删改查
  • 免手写 JS 的交互逻辑
  • 免手写 HTML 的标签结构

小测验

为什么数据库 Entity 不能用 record？

  • record 不能定义任何字段
  • record 缺少无参构造方法
  • record 无法被序列化处理
  • record 不支持继承扩展

小测验

selectList(null) 中的 null 表示什么？

  • 无条件查询返回所有行
  • 数据库连接对象为空值
  • 查询结果列表返回空值
  • SQL 语句存在空值错误
