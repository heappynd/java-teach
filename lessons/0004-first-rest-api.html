第 4 课：编写第一个 REST API

预计用时：25 分钟 | 难度：入门 | 前置知识：第 3 课 创建项目

目标：写一个能用的 API

你的 Spring Boot 项目已经跑起来了，但还没有接口。这节课我们要实现：

  1. 一个 GET 接口：返回问候语 { "message": "Hello, World!" }
  2. 一个带参数的 GET 接口：/hello?name=Vue -> { "message": "Hello, Vue!" }
  3. 一个 POST 接口：接收请求体数据并返回

写完后你就能用浏览器和前端工具调用这些 API 了，就像你平时调后端接口一样。

Express vs Spring Boot：概念对照

你写前端时一定见过 Express/Koa 的路由，Spring Boot 的做法非常相似：

Express.js（你熟悉的）

app.get('/hello', (req, res) => {
  res.json({
    message: `Hello, ${req.query.name || 'World'}!`
  })
})

app.post('/echo', (req, res) => {
  res.json({
    received: req.body
  })
})

Spring Boot（今天学的）

@RestController
public class HelloController {

  @GetMapping("/hello")
  public Map hello(
      @RequestParam(defaultValue = "World")
      String name) {
    return Map.of("message",
      "Hello, " + name + "!");
  }

  @PostMapping("/echo")
  public Map echo(
      @RequestBody String body) {
    return Map.of("received", body);
  }
}

核心逻辑完全一样：定义 URL 路径 -> 获取请求参数 -> 返回 JSON。只是语法不同。

开始写代码

创建 Controller 类

在 IDEA 中，右键 controller 包（com.yourname.demo.controller）-> New -> Java Class，命名为 HelloController。

目录结构会变成：

src/main/java/com/yourname/demo/
├── DemoApplication.java       <-- 启动类（已有）
└── controller/
    └── HelloController.java   <-- 新建的控制器

什么是 Controller？

Controller 就是处理 HTTP 请求的类，相当于前端 Express 里的路由处理器。前端发请求到某个 URL，Controller 负责接收并返回数据。

关于包结构

本课新建的 controller 子包用于存放所有 API 控制器。如果还没有这个包，右键 com.yourname.demo -> New -> Package 创建。随着项目增长，你还会建 entity、mapper、service 等子包，详见 第 10 课：Java 包与项目结构。

写第一个 GET 接口

将 HelloController.java 内容替换为：

package com.yourname.demo.controller;

import org.springframework.web.bind.annotation.*;

import java.util.Map;

@RestController
public class HelloController {

    @GetMapping("/hello")
    public Map hello() {
        return Map.of("message", "Hello, World!");
    }
}

逐行解读：

代码 含义
@RestController 告诉 Spring：这个类处理 HTTP 请求，返回值自动转成 JSON。相当于 Express 的路由模块
@GetMapping("/hello") 注册一个 GET 路由 /hello。相当于 app.get('/hello', ...)
public Map<String, String> hello() 方法返回一个 Map。Spring 自动将 Map 转成 JSON 对象 {"message": "Hello, World!"}
Map.of("message", "Hello, World!") 创建一个键值对。Map.of 类似 JS 的 { message: "Hello, World!" }

关键发现

你不需要手动调用 JSON.stringify() 或 res.json()。Spring Boot 自动把返回的对象转成 JSON，就像 Express 的 res.json() 帮你做了一样。

不支持

Map.of() 是 JDK 9+ 引入的不可变 Map 工厂方法，JDK 8 中不可用。本课所有 Map.of() 调用的 JDK 8 替代写法：

// JDK 8 写法
Map<String, String> result = new HashMap<>();
result.put("message", "Hello, World!");
return result;

单键值对时也可用 Collections.singletonMap("message", "Hello, World!")。国内 JDK 8 项目中常用 Lombok 的 @Builder 或直接 new HashMap。

运行并测试

点击 DemoApplication 旁边的绿色三角形运行项目（如果已经在运行，DevTools 会自动重启）。

浏览器打开 http://localhost:8080/hello，你会看到：

{"message":"Hello, World!"}

这就是你的第一个 API！和你在前端用 axios 调用的接口一模一样。

添加带参数的接口

在 HelloController 中添加第二个方法：

@GetMapping("/greet")
public Map greet(
        @RequestParam(defaultValue = "World") String name) {
    return Map.of("message", "Hello, " + name + "!");
}

解读新注解：

注解 前端类比 含义
@RequestParam req.query.name 获取 URL 查询参数。?name=Vue 中的 Vue
defaultValue = "World" req.query.name || 'World' 参数默认值，不传时用 "World"

测试：

  • 访问 http://localhost:8080/greet -> {"message":"Hello, World!"}
  • 访问 http://localhost:8080/greet?name=Vue -> {"message":"Hello, Vue!"}

写一个 POST 接口

GET 接口能用浏览器测，POST 接口需要发请求体。在 Controller 中添加：

@PostMapping("/echo")
public Map echo(@RequestBody String body) {
    return Map.of("received", body);
}
注解 前端类比 含义
@PostMapping("/echo") app.post('/echo', ...) 注册 POST 路由
@RequestBody req.body 获取请求体的数据。相当于 Express 中 express.json() 解析后的 req.body

用浏览器没法直接测 POST。你可以用以下任一方式测试：

方式一：在浏览器控制台用 fetch

fetch('http://localhost:8080/echo', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name: 'Vue', age: 7 })
}).then(r => r.json()).then(console.log)

方式二：用 IDEA 自带的 HTTP Client

在项目中新建一个 test.http 文件，写入：

### 测试 POST 接口
POST http://localhost:8080/echo
Content-Type: application/json

"Hello from IDEA"

点击请求上方的绿色运行按钮，就能看到响应。

Spring Boot API 注解速查

注解 前端类比 用途
@RestController Express 路由模块 标记类为 API 控制器，返回值自动转 JSON
@GetMapping("/path") app.get('/path', handler) 定义 GET 接口
@PostMapping("/path") app.post('/path', handler) 定义 POST 接口
@PutMapping("/path") app.put('/path', handler) 定义 PUT 接口
@DeleteMapping("/path") app.delete('/path', handler) 定义 DELETE 接口
@RequestParam req.query.xxx 获取查询参数 ?key=value
@PathVariable Vue Router 的 :id 获取路径参数 /users/42 中的 42
@RequestBody req.body 获取请求体（POST/PUT 的 JSON 数据）

小测验

@GetMapping 和 @PostMapping 的区别是什么？

  • 功能完全相同只是名字不同
  • 分别处理 GET 和 POST 请求方式
  • GetMapping 比 PostMapping 更快
  • PostMapping 只能用于删除操作

小测验

前端发送 POST 请求带 JSON body，后端用什么接收？

  • 用 @RequestParam 接收
  • 用 @RequestBody 注解接收
  • 用 @PathVariable 接收
  • 用 @GetMapping 接收

小测验

Spring Boot 方法返回 Map 时，响应是什么格式？

  • 返回纯文本字符串
  • 自动转换为 JSON 对象
  • 返回 XML 格式数据
  • 需要手动转格式才行
