第 1 课：在 Windows 上安装 JDK

预计用时：15 分钟 | 难度：入门 | 前置知识：无

为什么要装 JDK？

写 Vue3 需要 Node.js，写 Java 后端需要 JDK（Java Development Kit）。它是 Java 的开发工具包，包含编译器和运行时环境。

前端（你已熟悉）

Node.js = JS 运行时 + npm 包管理

没有 Node.js → 不能运行 JS 代码

后端（今天学的）

JDK = Java 编译器 + JVM 运行时

没有 JDK → 不能编译和运行 Java 代码

JDK 有很多发行版，就像 Node.js 也有官方版、nvm 管理版等。我们选 Eclipse Temurin（由 Adoptium 提供），它是免费开源的 OpenJDK 发行版，也是社区最主流的选择。

选哪个版本？

Java 版本号带 LTS（Long Term Support）标记的是长期支持版，相当于 Node.js 的偶数版（稳定版）。目前主流选择：

版本 类型 推荐场景
JDK 17 LTS 新项目首选，Spring Boot 3.x/4.x 最低要求，生态最成熟
JDK 21 LTS（最新） 可选，部分新项目采用

本课程使用 JDK 17

Spring Boot 最新版（4.x）支持 JDK 17 和 21。我们选 17，它是生态最成熟、企业采用率最高的 LTS 版本。

开始安装

下载 JDK 安装包

打开 Adoptium 下载页面，选择：

  • Version: 17 - LTS
  • Operating System: Windows
  • Architecture: x64（大部分 Windows 电脑选这个）

在下载列表中找到 .msi 安装包（Windows Installer），点击下载。

小贴士

如果你不知道自己的 CPU 架构，按 Win + Pause 打开系统信息，看"系统类型"。大部分是"x64-based processor"。

运行安装程序

双击下载的 .msi 文件，按以下步骤操作：

  1. 点击 Next
  2. 接受许可协议，点击 Next
  3. 重要！在"Custom Setup"页面，找到 Set JAVA_HOME variable 选项，将其改为 Will be installed on local hard drive。这会自动设置 JAVA_HOME 环境变量。
  4. 同样确保 Add to PATH 选项也是 Will be installed on local hard drive
  5. 点击 Install，等待安装完成

关键步骤

第 3、4 步最重要！如果不设置 JAVA_HOME 和 PATH，系统找不到 Java 命令。这就像装了 Node.js 但没加到 PATH，终端里输 node 会报"找不到命令"。

验证安装

安装完成后，关闭所有已打开的终端窗口（环境变量更新需要重启终端），然后打开一个新的 PowerShell 或 CMD 窗口，输入：

PS C:\> java -version
openjdk version "17.0.x" 2024-xx-xx
OpenJDK Runtime Environment Temurin-17.0.x (build 17.0.x+x)
OpenJDK Runtime Environment Temurin-17.0.x (build 17.0.x+x, mixed mode, sharing)

再输入：

PS C:\> javac -version
javac 17.0.x

如果两条命令都输出了版本号（17 开头），恭喜你，JDK 安装成功！

  • java = 运行 Java 程序的命令（相当于 node）
  • javac = 编译 Java 代码的命令（相当于 tsc）

如果验证失败了怎么办？

如果终端提示"不是内部或外部命令"或"command not found"，说明 PATH 没设置好。手动修复：

  1. 按 Win + S，搜索"环境变量"，点击"编辑系统环境变量"
  2. 点击"环境变量"按钮
  3. 在"系统变量"中找到 Path，点"编辑"
  4. 点"新建"，添加 JDK 的 bin 目录路径，通常是：
    C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot\bin
  5. 在"系统变量"中点"新建"，添加 JAVA_HOME，值为 JDK 安装目录（不含 bin）：
    C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot
  6. 确定保存，重启终端，再次验证

理解 JAVA_HOME 和 PATH

前端类比

PATH 里加了 node 的路径，所以你终端里能直接输 npm、node

NODE_PATH 告诉工具去哪找 Node.js

后端概念

PATH 里加了 java 的路径，所以终端里能直接输 java、javac

JAVA_HOME 告诉 Maven 等工具去哪找 JDK

小测验

JDK 和 Node.js 在各自生态中扮演的角色有什么共同点？

  • 它们都是代码编辑器，用来写代码
  • 它们都提供运行时环境，让代码能被执行
  • 它们都是包管理器，用来安装依赖
  • 它们都是框架，提供 UI 组件库

小测验

安装 JDK 后，为什么要设置 JAVA_HOME 环境变量？

  • 不设置 Java 代码无法编译
  • 其他工具如 Maven 需要它定位 JDK
  • 它是 Java 代码的运行目录
  • 它存储 Java 项目的源代码
